LaserGrid Anomaly Localization

A drone-mounted detection system that locates runway hazards with 30 cm precision using laser, video, and GPS/IMU telemetry.

Project Description

This project focused on developing an intelligent anomaly localization system to detect and map hazards on airport runways — such as debris, cracks, or foreign objects — with high accuracy. By fusing laser line projections, aerial camera footage, and GPS/IMU telemetry, the system converts visual anomalies into precise GPS coordinates.

  • Team: 3 members
  • My Role: Led geospatial logic design, video-telemetry synchronization, and ArcGIS validation

Problem Solved

Manual runway inspections are time-consuming, error-prone, and sometimes unsafe. Our goal was to build an automated, drone-compatible solution that could identify anomalies in real time and report their exact geolocation to airport maintenance teams.

My Contribution

  • Developed the distance estimation algorithm using FOV and laser distortion
  • Built the synchronization pipeline for video frames and GPS/IMU logs
  • Converted compass heading and orientation into GPS coordinates
  • Mapped and validated predictions using ArcGIS
  • Designed the output format: geo-tagged anomaly reports with image, time, and coordinates

Outcomes

  • Achieved <30 cm geolocation error across test scenarios
  • Generated real-world anomaly reports with auto-captured images
  • Validated superiority of FOV-based estimation over static calibration

Key Learnings

  • Mastered sensor fusion under field conditions
  • Improved drone telemetry handling and Z-angle correction
  • Hands-on with ArcGIS for spatial validation
  • Translated raw data into actionable, human-readable reports

Process & Challenges

  • Video-GPS Sync: Aligned separate time domains using timestamp logic
  • Laser Distortion: Handled variable textures and lighting with adaptive preprocessing
  • Drone Stability: Applied dynamic Z-angle correction during flight

Narrative

This was more than a data project — it was an applied innovation story. Each drone flight generated real-time insights: object detection snapshots, GPS locations, and reports we could hand to airport safety teams. I wasn’t just writing math — I was building systems that see the world, make sense of it, and help keep it safer.
